# 经典三国杀 · DIY武将

晋司马懿与魔张角的手机浏览器试玩版，支持与电脑对战。

网址：https://wm198363.github.io/

GitHub Actions 首次从既有试玩站获取游戏快照，逐文件检查大小和 SHA-256，将完整游戏保存至 `game-assets` 分支，并部署 GitHub Pages。后续发布直接读取该分支，运行中的游戏不依赖原托管平台。
